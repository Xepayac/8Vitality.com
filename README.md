# Infinite Vitality Website

This is the source code for the Infinite Vitality website (8Vitality.com).

## Structure
- `index.html`: Main landing page.
- `css/`: Stylesheets.
- `resources/`: Images and documents.
- `legacy_backup/`: Archived files from the previous RapidWeaver version.

## Deployment
This site is deployed via cPanel Git Version Control.
1. Connect via cPanel.
2. Clone/Pull to `public_html`.
